# Фонд святой Екатерины — сайт

Редизайн святаяекатерина.рф. Сейчас в репозитории концепт главной страницы (тёмный вариант v1), светлый вариант в работе.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080. Заставка показывается один раз за сессию вкладки.

## Работа в Claude Code

```bash
cd ~/projects/saint-ekaterina-site
claude
```

Задачи лежат в `docs/prompts/`. Чтобы запустить задачу, напишите в Claude Code: «Выполни задачу из docs/prompts/01-svetlaya-versiya-oblaka.md».

## Документы

- `CLAUDE.md` — контекст проекта для Claude Code: структура, функционал, правила, проверка.
- `docs/concept-v1.md` — как устроен концепт и что сделать перед запуском сайта.
- `docs/references.md` — референсы клиента и стили из Refero.

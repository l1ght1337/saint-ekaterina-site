# Концепт v1 (тёмный)

Концепт редизайна святаяекатерина.рф в духе rmk-group.ru: тёмный «кинематографичный» первый экран, крупная типографика с волосяными линиями, панель-слайдер, золотая 3D-эмблема с заставкой «литьё». Весь текущий функционал сохранён.

## Как открыть

- `python3 -m http.server 8080` в корне репозитория, затем http://localhost:8080. Можно и двойным кликом по `index.html`. Нужен интернет: шрифты Google Fonts и фото подгружаются с сайта фонда и Викисклада.
- Заставка показывается один раз за сессию вкладки. Чтобы посмотреть её снова, откройте страницу в новой вкладке. Пропустить заставку можно кнопкой, прокруткой или любой клавишей.
- Если в системе включено «Уменьшить движение», заставки нет, эмблема статична.

## Как устроена 3D-эмблема

- Контур логотипа лежит в `<symbol id="emblem">` в `index.html`.
- Скрипт рисует контур в canvas, строит поле расстояний (SDF) и рендерит объёмную золотую эмблему рэймаршингом прямо в браузере, без сторонних библиотек.
- **Чтобы поставить официальный вектор**, замените атрибут `d` (и `viewBox`, если он другой) у `<symbol id="emblem">`. 3D-модель, иконка в шапке и подвале обновятся сами.
- Текущий контур векторизован с PNG 100×185 px с сайта. Для боевой версии нужен оригинал логотипа (AI, SVG или PDF).
- Если WebGL2 недоступен, показывается плоская SVG-эмблема. Разрешение рендера само снижается на слабых видеокартах.

## Что сделать перед запуском

1. **Логотип**: получить вектор у фонда (см. выше).
2. **Фото**: сейчас фото подгружаются по ссылкам. Для сайта их нужно скачать и разместить у себя. Попросить у фонда фото: выдача продуктовых наборов, горячая линия и волонтёры, Михайловский храм в Новоипатово, Свято-Елисаветинская обитель, ветераны, День Героев, выставка Музеев Кремля.
3. **Шрифты**: Old Standard TT и Golos Text (лицензия OFL) лучше разместить на своём сервере, а не грузить с Google Fonts.
4. **Формы**: в концепте они проверяют поля и показывают «Отправлено», но ничего не отправляют. На сайте заменить на шорткоды Contact Form 7 (форма заявки на набор — `id="400"`), имена полей уже совпадают с CF7 по умолчанию (`your-name`, `your-email`, `your-message`).
5. **События**: выводить последние 10 записей через `WP_Query` (миниатюра, дата, заголовок).
6. **Тексты на согласование**: «Одинокие инвалиды» заменено на «Одинокие люди с инвалидностью»; короткие подписи к проектам и подзаголовок первого экрана написаны по материалам сайта и новостей.

## Безопасность текущего сайта

Внизу страниц сайта вшиты посторонние ссылки на сайты с «нулёными» темами WordPress (downloadthemefree.com, null24h.net), сайт работает на теме Jupiter 5.7 2017 года. Это похоже на пиратскую или взломанную тему. При переезде на новый дизайн лучше не переносить старую тему, а сделать свою, проверить сайт на вредоносный код и обновить WordPress и плагины.

## 3D-модель отдельным файлом (для видео, Blender, AR)

Blender: File → Import → Scalable Vector Graphics → `assets/emblem.svg` → во вкладке Object Data: Geometry → Extrude 0.02, Bevel Depth 0.004 → Object → Convert → Mesh → материал: Metallic 1, Roughness 0.25, цвет золота → File → Export → glTF 2.0 (.glb).

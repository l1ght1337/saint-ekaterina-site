# Референсы

## Эталон клиента: rmk-group.ru
Тёмный кинематографичный первый экран с 3D-видео (медные каркасные пирамиды), огромный тонкий гротеск с волосяными линиями под строками, панель-слайдер внизу справа с нумерацией слайдов, светлый раздел «Цифры» с крупными медными числами, текст, проявляющийся при прокрутке, подвал в колонках. Шрифт Suisse Intl, акцентный цвет — медь.
